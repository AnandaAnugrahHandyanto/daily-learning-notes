## Key Decisions
- Use host MariaDB 11.8 as primary DB over Docker (mysql:8.0 ibtmp1 EPERM, mariadb:11 socket bind Operation not permitted) and SQLite fallback — host DB accessible via `mysql -u root -p[REDACTED]` and `CREATE DATABASE` succeeded (DB_EXIT:0)
- Render PNGs via local Pillow (900x300 to 2000x1350) instead of native MCP export — `@drawio/mcp` has no PNG export tool, only validation via `list_pages`/`get_page`; drawio files remain editable and backed up to `09 - Backup/`
- Inject `pdo_sqlite.so`/`sqlite3.so` via `/home/savarez/bin/php` wrapper (`-d extension=...`) extracted from `php8.4-sqlite3` deb — avoids global `sudo apt install` while keeping sqlite driver available for fallback
- Switch `SESSION_DRIVER` from `database` to `file` with `SESSION_LIFETIME=120` — file driver resolved logout/login sticking (Cache-Control: no-cache verified) and left DB sessions table unused (11 rows orphaned)
- Represent Laravel OOP in Class Diagram with `«Model»` stereotypes, Controller methods `index()/store()/update()/destroy()`, and Eloquent relations — aligns diagram with Laravel 13 conventions
